
Software Development Environment Lab Exercises

Exercise 1: Development Environment Setup Planning (Team of 2)
Objective: Plan and document a development environment setup without actually installing software.

Scenario Selected:
Building a simple website - Build a simple business website with text, images, and contact forms

Environment Planning:

IDE: Visual Studio Code (VS Code)

Additional tools: Git, Node.js, Live Server extension, Prettier, GitHub

Hardware requirements: 8 GB RAM, 256 GB SSD, modern CPU, internet connection

Team collaboration needs: GitHub repository, VS Code Live Share, shared task list (Trello/Notion)

Estimated setup time and complexity: 1–2 hours, low complexity

Tool Justifications:

VS Code: Free, lightweight, supports HTML/CSS/JS, large extension library.

Git/GitHub: Version control, easy team collaboration.

Node.js: Needed for local development server and package management.

Live Server: Auto-refresh browser on save.

Prettier: Consistent code formatting.

Live Share: Real-time collaborative editing.

Setup Guide Creation – Step-by-Step Checklist:

Install VS Code from official website.

Install Git from official website.

Create GitHub account and new repository.

Install Node.js from official website.

Open VS Code → Extensions → install Live Server, Prettier, Live Share.

Clone GitHub repository to local machine.

Create basic project files: index.html, style.css, script.js.

Open project in VS Code, right-click index.html → Open with Live Server.

Test contact form locally.

Commit and push changes to GitHub.

Deliverable:
Complete development environment setup plan with tool justifications and installation checklist.
